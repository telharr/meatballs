# Mod skeleton

Copy this folder to `src/mods/<YourMod>/`, then:

1. Rename `REPLACE_ME` in `mod.info` and Lua files to your mod id.
2. Rename Lua files from `REPLACE_ME*.lua` to match.
3. Add `poster.png` (optional but recommended for Workshop).

Do not develop inside `templates/` — it is a pristine scaffold only.
