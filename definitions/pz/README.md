# Project Zomboid Lua stubs (Lua Language Server)

These `@meta` files teach **sumneko.lua** about Kahlua2 globals. They are **not** loaded by the game and must not be copied into `src/mods/`.

| File | Covers |
|------|--------|
| `events.lua` | `Events`, ModData, network helpers |
| `isoobjects.lua` | `IsoPlayer`, `IsoGridSquare`, items/containers |
| `traits_perks.lua` | Traits, Perks, WorldDictionary |

Referenced from `.luarc.json` and `.vscode/settings.json` via `definitions/pz`.
