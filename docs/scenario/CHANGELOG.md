# Changelog — scenario

Формат: версия, дата, сезон, что изменилось. Не стирать старые строки.

## 0.4.8 — 2026-09-05 — s00

- c04: повтор канистры один раз, если `c04_can` нет в мире; третьей нет.
- Метка `from_south_pump` на наполнении; ванильный сифон с машин сбрасывает метку и запрещён на квестовой таре.
- Цистерна cap 80: гонка сдач → overflow «под верстак», шкала не > 80, флаги обоим.

## 0.4.7 — 2026-09-05 — s00

- ТЗ c04 «Сухой бак Дойла»: `s00/quests/c04-fuel.md` (пешком на южную АЗС, ≥ 8 L, лист №14).
- B42: сдача по объёму Gasoline, не по смене `EmptyPetrolCan`→`PetrolCan`. Насос без сети — TimedAction со шлангом.
- Чужой бак: свои восемь + тот же бардачок. Мотор в городе — штраф до рассвета, не вайп.

## 0.4.6 — 2026-09-05 — s00

- c03: свет B42.20 — `setActive` / `setIsActive` / `IsoThumpable:toggleLight()` + `transmitCustomModData()`, kind на старте мира.
- Шкаф спальни пастора: гарантия 2× `Base.Sheet` (пустые руки после бинтов c02).
- Штрафной спавн 3–6: кромка южного поля, вне `CanSee`, не на крыльце.

## 0.4.5 — 2026-09-05 — s00

- ТЗ c03 «Ночной дозор на Черч-стрит»: `s00/quests/c03-church.md` (стелс, лампа, две шторы, записка Рен).
- Провал попытки по шуму/стеклу — ретрай до следующего заката, не вайп. Чужой дозор: sneak к той же записке.

## 0.4.4 — 2026-09-05 — s00

- c02: TimedAction кипятка проверяет `getHeat()` и зажигает конфорку по баллону — без wait-loop на мёртвой сети.
- Запас простыней c03 можно порвать; журнал и Марго шлют в дома через дорогу (Черч-стрит), логика главы жива.
- Учебный порез: грейс 15 мин реального времени, без летального `ReduceGeneralHealth` у плиты.
