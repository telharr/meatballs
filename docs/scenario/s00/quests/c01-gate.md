## 1. Нарратив и диалоги

**Место выдачи:** Ash, ворота части `8080, 11750, z=0`. Сидит на ящике, грязная повязка, смотрит на пролом `8142, 11752`.

**Обоснование:** позавчера орда шла на свет фар. Рен завела грузовик в створку, чтобы пробить выезд. Дойл матерился. В проломе сквозняк с трассы и запах мертвечины. Если до сумерек не закрыть — ночью зубы на шее.

### Выдача

Ash не здоровается.

> Они шли на свет фар позавчера. Рен завела грузовик прямо в ворота, чтобы пробить заслон на выезде. Дойл матерился, но она не слушала. Теперь сюда тянет сквозняк с трассы и запах мертвечины. Если до сумерек не закроешь брешь — ночью мы проснемся с зубами на шее. За сараем лежат балки. Дотащишь — научу, как держать молоток, чтобы не отбить пальцы.

Сарай / балки: `8165, 11760, z=0`.

### Сдать без инструментов (нет молотка, или гвоздей < 4, или досок < 2)

Игрок жмёт «готово» / контекст створки / говорит Ash. Ash не принимает.

Нет молотка:

> Молоток. Не кулак. Не приклад. Молоток. Иначе пальцы будут как у Томми после лестницы.

Нет гвоздей (или < 4):

> Доски без гвоздей — это щель с лишним деревом. Четыре гвоздя. Не три. Не «потом донесу».

Нет досок (или < 2):

> Я сказал: сарай. Балки. Распил. Две доски на пролом. Пока таскаешь — не беги. Спина не казённая.

Перегруз (персонаж `tooHeavy` / вес выше максимума в момент сдачи или у створки):

> Поставь. Сейчас. Колени не казённые. Смена без хромого плотника ещё как-нибудь, без хромого новичка — тоже.

Повторная попытка сразу после отказа — короче:

> Инструменты. Потом разговор.

### Успех (створка забита, сервер подтвердил)

> Держит. Не красиво — держит. Сквозняк сдох. Запах нет. Иди к Марго, пока гвоздь из ворот не напомнил, что ржавчина тоже кусается.

### Жетон Кеннеди (осмотр / разговор после лута)

Предмет выдаётся **с сервера** в момент закрытия пролома: выпадает из паза, не лежит заранее на земле (иначе сперва лут, потом квест).

Ash, если игрок показывает жетон или открыт inspect:

> Не наш. Армия бросила блокпост у шоссе 11 июля. Рен притащила этот жетон с разведки. Сказала, помощи не будет, округ отписан под ноль.

Если игрок выбросил жетон:

> Подбери. Это не сувенир. Это приговор округу. Марго впишет, если доживёшь до книги.

## 2. Спринт / ТЗ Lua и backend

Ветка работ: **`mod`**. Сценарий не мержить. Коммит: `feat(mod:MeatballsNadzor): s00-c01 gate repair`.

### Цели спринта (один PR-размер)

1. Интерактивный тайл пролома.
2. TimedAction заколачивания с проверкой инвентаря **на сервере**.
3. Замена спрайта / объекта створки, репликация клиентам.
4. Флаг игрока + выдача жетона один раз.
5. Перегруз балок с сарая не ломает сервер и не обходится «в кармане воздуха».

### Координаты

| Объект | X | Y | Z |
|--------|---|---|---|
| Ash (диалог) | 8080 | 11750 | 0 |
| Створка / пролом | **8142** | **11752** | **0** |
| Сарай, балки | 8165 | 11760 | 0 |

Радиус взаимодействия створки: персонаж на том же `z`, дистанция ≤ 2 тайла. Иначе отказ без анимации.

### Предметы

| Роль | FullType | Кол-во |
|------|----------|--------|
| Молоток | `Base.Hammer` | ≥ 1 (не съедать) |
| Гвозди | `Base.Nails` | ≥ **4** (съедать 4 при успехе) |
| Доски | `Base.Plank` | ≥ **2** (съедать 2 при успехе) |
| Балки у сарая | `Base.Log` и/или квестовая `MeatballsNadzor.ShiftBeam` (вес ≥ 8) | тащить к пиле / крафт в доски ванилью |
| Награда | `MeatballsNadzor.KennedyDogTag` | 1 |

Имя `Item_KennedyDogTag` в ТЗ заказчика = **DisplayName / внутренний id**. В скрипте B42:

```text
module MeatballsNadzor
item KennedyDogTag
```

Полный тип: `MeatballsNadzor.KennedyDogTag`. Иконка: заляпанный металл. `Weight = 0.1`. Не стек. `Tooltip` короткий: `KY NG · KENNEDY`.

### Проверки сервера (обязательны)

Клиент шлёт `sendClientCommand("MeatballsNadzor", "repairGate", { x=8142, y=11752, z=0 })`.

Сервер:

1. `player` жив, не nil, не в машине.
2. Квадрат существует, координаты совпадают (не доверять клиентскому «я починил»).
3. Флаг `MeatballsNadzor_s00_q01_gate_repaired` на **этом** игроке ещё false. (Мир: пролом общий — см. ниже.)
4. Инвентарь: `Hammer` ≥ 1, `Nails` ≥ 4, `Plank` ≥ 2. Считать контейнеры на поясе, не лут на земле.
5. Перегруз: если `player:getInventory():getCapacityWeight()` > `player:getMaxWeight()` — **не стартовать** TimedAction; клиенту реплика Ash про колени. Таскание балок с сарая должно реально давить вес (не `Weight=0.1` на бревне).
6. Только после TimedAction **success** на сервере: снять 4 гвоздя и 2 доски, молоток оставить.

Dedicated: не вешать логику только на `OnTick`. TimedAction + `OnClientCommand`. Поллер как в Safehouses, если понадобится файл — не для этой главы.

### Общий пролом vs флаг игрока

Створка **одна на мир**. Первый успешный ремонт меняет спрайт для всех.

- Мир: `ModData` ключ `MeatballsNadzor_World.s00_gate_repaired` (boolean), `transmit`.
- Игрок, который забил: `player:getModData().MeatballsNadzor_s00_q01_gate_repaired = true` — заказчик просил имя `s00_q01_gate_repaired`; **хранить с префиксом мода**, в коде читать оба при миграции, писать только префиксный.
- Жетон: только тому, кто завершил TimedAction, и только если у него ещё нет `KennedyDogTag` и флага выдачи `MeatballsNadzor_s00_q01_tag`. Повторно не выдавать. Кто пришёл к уже забитой створке — квест «осмотреть паз» / Ash рассказывает жетон, предмет не дублировать (лор: один жетон).

Если пролом уже забит миром, а игрок новый: глава 1 для него — разговор с Ash + запись в журнале, без второго ремонта. Жетон не фармится.

### Триггеры завершения

1. Клиент: контекстное меню на объекте пролома → TimedAction (анимация ударов, звук молотка ванильный `Hammering` / аналог).
2. Прогресс 0..1 слать в UI (блок 3). Обрыв действия (орда, отход) — без съедания гвоздей.
3. Сервер success:
   - спрайт/объект створки: сломанный гаражный проём → забитый / баррикада (ванильный barricade на `IsoDoor`/`IsoThumpable`, если объект дверь; иначе replace sprite и не регистрировать новый tiledef без нужды);
   - `s00_q01_gate_repaired` (префикс) = true на игроке;
   - мир `s00_gate_repaired` = true;
   - `player:getInventory():AddItem("MeatballsNadzor.KennedyDogTag")`;
   - `sendServerCommand` клиенту: `gateRepaired`, `showDogTagInspect`.
4. Реплика успеха Ash — только если игрок в радиусе 8 тайлов от `8080,11750`.

Никаких `WorldDictionary` новых entity, если обходимся предметом + ModData.

### Тест-план (smoke)

- Без молотка / 3 гвоздя / 1 доска: действие не стартует, реплика отказа.
- Перегруз у створки: отказ.
- Успех: −4 nails −2 plank, hammer на месте, спрайт, флаг, один жетон.
- Второй игрок после ремонта: пролом закрыт, жетона нет.
- Hosted listen + dedicated: спрайт виден обоим.

## 3. ТЗ агенту «мододел» — UI / UX

Ветка **`mod`**. Не панель. Ванильный стек: `ISPanel`, `ISUIElement`, `ISButton`, `ISLabel`, `ISScrollingListBox`, `ISProgressBar` (или полоса через `drawRect` как в ISInventoryPage). Без HTML, без кастомных шрифтов вне PZ. Текстуры — `media/ui/` мода, не воровать UI The Indie Stone пачкой.

### 3.1 Журнал смены «Записи дежурства»

Новое окно `ISNadzorDutyLog` (имя класса префикс Nadzor). Открытие: горячая клавиша или кнопка у Ash после выдачи c01.

- Заголовок: `Записи дежурства`.
- Список глав смены. Строка c01: `Дыра в караулке` + статус `открыто` / `створка держит` / `жетон найден`.
- Клик по строке: короткий текст из выдачи Ash (не простыня лора).
- Закрытие: ванильный `X`, Escape.
- Данные статуса только с сервера (ModData), клиент не «рисует победу» до флага.

Макет: как `ISQuestWindow` / journal mods — левая колонка список, правая текст. Отступы 4px, кнопки `ISButton` высотой как инвентарь.

### 3.2 Плашка ремонта створки

Пока идёт TimedAction у `8142,11752`:

- Маленький `ISPanel` якорь низ экрана / над hotbar, не перекрывать инвентарь целиком.
- Текст: `Створка ворот`.
- Прогресс-бар 0–100% от `action:getJobDelta()`.
- Срыв действия — панель `close()`.
- Успех — вспышка текста `Держит.` 2 сек, затем закрыть.

Не делать круговой MMO-каст. Прямой бар, как ремонт в ванили.

### 3.3 Осмотр жетона

По `showDogTagInspect` или ПКМ по предмету → `Inspect`:

- Окно `ISNadzorItemInspect`, размер ~280×220.
- Текстура жетона: металл, грязь, вмятина (одна PNG в `media/ui/nadzor_kennedy_tag.png`). Не градиенты в коде.
- Текст: `KENNEDY · KY NG` + строка «паз створки, 11 июля».
- Кнопка `Спрятать в карман` — закрывает UI, предмет уже в инвентаре (не клонировать).
- Escape = то же, что кнопка.
