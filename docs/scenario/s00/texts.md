# Листы хроники

Квестовые предметы. Не макулатура на продажу. Не Discord.

## Жетон Кеннеди (`c01`)

Раздавлен в пазу ворот. Гравировка: `KENNEDY · KY NG`.

В мире это значит: 11 июля нацгвардия снялась с блокпоста у шоссе. Округ отписан. Помощи не будет.

Один металл на мир. Если потерян (`kennedy_state = lost`) — не второй жетон, а **`KennedyFieldReport`**: углярная копия в столе офиса `8136,11730,z=1` и, пока офис закрыт, в ящике кухни Марго.

```text
КОПИЯ / РАЗВЕДКА
11 июля 1993
Блокпост KY NG снят. Округ отписан.
Помощи не будет. — Рен, со слов жетона KENNEDY
```

## Тетрадь Марго (`c02`)

Сорок строк. Часть вычеркнута «заражение / нет воды». Шестая строка — брат Марго. Новичок вписывается отдельно, как живой. Не в этот список мёртвых.
