# Сезон 00 — Пожарка

Первый сезон сервера не про войну крыш. Он про один жест: человек выбирает **Надзор** до входа в мир и учится жить сменой.

## Состояние мира

- Knox Country, зима после Event. Ограда стоит.
- Открытая фракция: **Надзор**. Штаб — пожарная часть Роузвуда (`8130, 11740`).
- Вторая дверь на старте: **поселенец**. Не фракция.
- **Хартия** закрыта. West Point — рейд, не столица.
- Луисвилл — мёртвая столица в лоре. Приват там не светят.
- Капитана нет. Рен Хейл мертва в тюрьме. Трое NPC держат смену.
- Экономика Роузвуда закрыта, пока игрок не пройдёт испытание капитана.
- Compact, McCoy, вторая крыша — не этот сезон.

## Победа сезона

Сезон 00 сыгран, когда капитан закрыл первую неделю стола (`q20–q25`) **и** пожарка всё ещё общий двор. Ключа мало. Титула мало. Нужны пайки, рейс, ордер, амбар, дрова и сирена с той стороны стола.
