# Сезон 00 — Хроника пустых коек

Не список поручений. Расследование: почему часть выжила и куда ушла Рен.

## Состояние мира

- Надзор. Пожарная часть Роузвуда. Пролом в воротах — Рен вырвалась грузовиком.
- Капитана нет. Тело в медблоке тюрьмы. Ушла за антибиотиками и дизелем, не за камерами.
- Эллис загрызен своими в караулке. Армия списала округ 11 июля.
- Сто дней в части до ключа дома и клятвы. Офис — с **25 суток** тела (c06), если Томми на доске.
- Капитан — тело Рен за стол вахты после рассвета (c07). Экономика — неделя стола после короны.
- Хартия закрыта. Поселенец хронику не играет.
