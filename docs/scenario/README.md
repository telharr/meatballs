# Сценарии MEATBALLS

Живая библия сезонов. Код панели и модов сюда не кладём. Ветка **`scenario`**. Не мержить в `main`, пока сезон не сказали готовым.

## Как устроено

| Путь | Роль |
|------|------|
| `CHANGELOG.md` | Версии. Каждое изменение лора — строка здесь |
| `s00/` | Нулевой сезон: ввод Надзора |
| `s01/` … | Следующие сезоны, когда появятся |

В шапке каждого файла сезона: `season`, `version`, `updated`. Номер версии файла и запись в changelog обязаны совпадать.

## Имена

Одна крыша — одно имя. **Надзор** — так называется фракция в мире и на создании персонажа. `НДЗ` — короткое поле ванильного тега (лимит PZ), не второе название.

## Ветка

```text
git fetch
git checkout scenario
git rebase origin/main
```

Коммиты: `docs(scenario): …`.
